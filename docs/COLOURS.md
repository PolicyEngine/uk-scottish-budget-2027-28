# Colours

Charts take every colour from `dashboard/src/utils/chartTheme.js`. Components never write a hex value (`utils.test.js` checks it).

| Use | Token | Hex |
|---|---|---|
| Gain | primary-600 | #2C7A7B |
| Loss | gray-400 | #9CA3AF |
| Neutral | gray-500 | #6B7280 |
| Grid | border-light | #E2E8F0 |
| First policy year | primary-700 | #285E61 |
| Second policy year | primary-300 | #4FD1C5 |

Selected chips and cards show by fill and border only, with no tick badges.
